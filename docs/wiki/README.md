# docs/wiki — 资料集（百科层）

本目录是《妹！生活 ～単色～》的**百科层**：纯数据手册，以表格和条目为主，
每个条目配一句简明说明，不做剧情化攻略。

## 证据分级

| 标记 | 含义 |
|---|---|
| `S` | 脚本一手：`CE编号@槽位` 的 op111/op150/op210 字面量、变量表行名 |
| `T` | 运行时实测：headless 冒烟断言、结局/相册 gating 实测、真实存档样本 |
| `G` | 社区攻略观测：可能取整、近似、定性 |
| `U` | 未验证 / 未定位：脚本找不到、资料矛盾或需实机确认 |

## 与 `docs/guide/` 的分工

| | `docs/wiki/`（本目录） | `docs/guide/` |
|---|---|---|
| 体裁 | 百科 / 数据手册 | 攻略正文（14 章叙述） |
| 组织 | 按对象分册（数值/物品/事件/角色/日程/收集） | 按读者动线分章（第 0–13 章） |
| 数字来源 | `docs/guide/数据定稿/01–12`（S 级定稿层） | 同左 |
| 互补 | 查表：某物品多少钱、某事件怎么进 | 叙述：按路线走通一周目 |

两层的数字同源于 `docs/guide/数据定稿/01–12`；**任何数值都应能回指到定稿某表某行**。

## 口径

- 三个版本口径分开写：引擎 ver2.22 / 数据格式世代 2.00（V200）/ 汉化显示副标题 Ver2.03。
- 社区攻略（`docs/wiki文档/`，gitignore，仅本地参考）只作 `G` 级交叉验证，**不照抄**。
- 姊妹作《妹相随》的定稿与正文属另一仓库，不互通。
- 成人内容只做中性技术记录：场景名、触发条件、数值门槛、分支、CG 编号。
